# Host health source seal

Prepared against `aa21a1d4c679ef737a6856f485d5141a179efc93`. Native compilation/tests, cloud, installed-product/model execution and full V13 integration are **NOT_RUN**. This package adds only `host_health.rs` and this reference; Controller owns module export, E health rows, H intent/receipt and pump integration. It adds no table, scheduler, retry policy, CLI patch, launch, credential access or acceptance.

## Interface and safety boundary

`observe_codex_host_health(db: &VerifiedDatabaseConnection, owner: &OwnerIssuer, custody: &PreparedCustody, key: &RawSourceKey) -> Result<Option<HostHealthProof>, HostHealthError>` reads already captured A bytes. These existing types replace the suggested `RpcSource`, which does not exist at the baseline. Both factory and `revalidate_host_health_in_transaction(db, owner, proof) -> Result<Seat, HostHealthError>` require an already open same-connection transaction; the existing native Owner check rejects autocommit. They open no transaction, send nothing and write nothing. H must retain its real custody and verify the held process through the existing `LaunchEvidence::verify_live` before observation/action; a SQL snapshot is not an operating-system handle check.

Private proof fields bind original domain/session/process, full PreparedCustody (ticket, nonce, PID, creation time, image digest, profile and generation), raw source epoch/cursor/event/bytes/SHA256, seat/incarnation/instance, original thread/work turn, two-case typed cause, and hashes of the original H send/receipt/RPC command/ACK. Getters include `domain_id`, `session_id`, `seat_id`, `incarnation`, `instance_id`, `generation` (i64), `process_operation_id`, `thread_id`, `turn_id`, `source_event_id`, `source`, `raw_sha256`, `raw_source_bytes`, `custody`, `work_send_request_id`, and `signal` (the existing E HealthSignal, only ContextCompact or RepeatedFailure). No constructor or conversion can manufacture a NativeSeatCall/ModelCallProof.

The factory reuses `current_codex_model_binding` solely for existing original-open, current fixed Codex pin, committed H claim, live E seat/home/instance and full physical custody checks, including the existing stop-intent fence. It does not call `model_call`, current model caller/tool checks, or require the failed turn to remain ACTIVE. WORK purpose and no active generation change are mandatory. The original failed terminal must be RESOLVED, its original event must have matching native domain/seat/session/epoch/tier, original raw cursor and failed Codex thread/turn/error metadata. The raw source cursor is distinct from the normalized event cursor. Only the first real terminal for this physical thread/turn can mint; later duplicate terminal frames return None while remaining in A, including when the first terminal has no actionable cause or is still pending normalization.

The ordinary work turn requires an actual H `send` APPLIED/createdTurn receipt with exactly body/generation, the original observed turn/start command, typed RPC ACK and receipt identity under the same custody/epoch. Notification/RPC scheduling order is not substituted for this source relationship. This includes a normally admitted child's existing dispatch send, as Controller confirmed; it does not pretend the journal has a User-exclusive origin column. Append and compact/control turns cannot substitute. Revalidation reconstructs the seal and compares all original bytes/hashes/relationships and current binding, so changed source, authorization, seat, custody, stop intent or generation transition cannot authorize an E/H mutation. Root must perform the actual action at its existing safe point and preserve the original intent/request/receipt through UNKNOWN; this source seal does not provide a send permit, receipt settlement or permission to rerun work.

The only accepted original `turn/completed` failed causes are `contextWindowExceeded` and the exact object `{responseTooManyFailedAttempts: {httpStatusCode: null | uint16}}`. The code uses the existing bounded LF/depth/RPC decoder and normalizer. Plain message/prose, ordinary error/willRetry true or false, usage/limit/budget/auth/sandbox errors, string retry names, missing status codes and unknown cause shapes yield no proof. The fixed schema's HTTP code is u16; the factory deliberately requires the explicit number/null field from this task's source contract. CLI retry exhaustion is its typed fact; the host does not count failures or invent a threshold.

Three small in-file security tests call the real typed extractor for positive causes and negative shape/prose/retry/success/usage/model-item controls. They construct no proof and create no DB fixture. They are **NOT_RUN** until Controller exports the new module and runs cloud native checks. These parser controls do not establish complete factory binding, physical pipe, E/H transaction, UNKNOWN recovery or V13 evidence; those remain Controller's integration verification.

## References adopted and differences

- Historical gogo-party `docs/design/06-context-session-governance.md`: source-backed health, safe points, terminal fences and UNKNOWN semantics. Its multi-dimension/old rotation policies are historical design references; no scheduler or threshold is imported.
- Repository `docs/research/adapter-spike/02-mvp-adapter-decision.md`: fixed protocol pin, original terminal event/IDs and the distinction between native health facts and token-percentage rotation. No percentage or capacity inference is added.
- Frozen `docs/design/gogoke-37-plan-v1/PLAN.json` E.2/V13: automatic low-key K-SESSION health action without an Owner prompt. `seat/continuity.rs` already maps ContextCompact to COMPACT and RepeatedFailure to RENEW. Current renew-session is native process generation recovery on the existing provider thread; Controller confirmed it does not claim an empty context/new provider conversation.
- Current `rpc_journal.rs`, `model_call.rs`, `ledger/mod.rs`, `codex_output.rs`, `generation_change.rs` and `product_database/v37_output.rs`: adopt the original H/A/custody and ordinary-send relationship checks while keeping model tool authority separate. A and its normalized event must be present before this proof is observed inside Root's existing transaction. This package does not change any existing source file.
- The independent private architecture recommendation was read as planning evidence only; it is not acceptance. Its separate-issuer/source/transaction advice is adopted; this package implements only the source seal.
- Official fixed Codex source [`shared.rs`](https://github.com/openai/codex/blob/a956835d020762cb2b570053af06f643a11c0ecc/codex-rs/app-server-protocol/src/protocol/v2/shared.rs#L73): actual camelCase typed variants and Option<u16> retry status, independently read at the pinned revision. Local vendored generated schema supplies the corresponding terminal/error shapes. A terminal error is an observed fact, not a model tool request or compact completion. The earlier generation comments naming 0.149 in existing native files do not supersede the actual current binding pin of 0.160.0.

Build constraints follow `docs/governance/gogoke-build-and-release.md`: no local native compiler or new executable is used. The tree is retained for Controller integration and cloud verification; this worker performs no acceptance or shared-tree cleanup.
