# M2 provider command encoding references

This unconnected Rust file encodes vendor stdin data only. The native H owner must supply the observed pinned executable, process and session generation, current grant, original RPC ID and journal, framing write, and later origin bound stdout capture. An encoded line or successful stdin write is no vendor receipt. `session/cancel` is a notification; a correlated prompt response with `stopReason=cancelled` is required even to claim the model turn was cancelled, and H separately proves process stop.

The ACP JSON-RPC ID is preserved as its native string or safe integer type via `provider_evidence/acp.rs::RpcId`; `atomic::JsonString` and `Json::canonical()` escape fields before the terminal LF. `PermissionResponse` returns `Unsupported` because the frozen ACP adapters do not encode a reply to `session/request_permission`. Only H can bind a server permission request to a current grant and an original request ID; this file cannot authorize it.

The fixed OpenCode `v1.18.32` service returns `configOptions` from `session/new` and `session/set_config_option`. Its `model` handler resolves a provider/model selector; `effort` rejects a value absent from that selected model's variants. The fixed agent implements `setSessionConfigOption`; the official ACP v1 schema maps that handler to `session/set_config_option` with `sessionId`, `configId`, and string `value`. H checks the actual same-process session before writing and the response's exact requested `currentValue` before OBSERVED. A `session/update` notification is only output. Sources: https://github.com/anomalyco/opencode/blob/v1.18.32/packages/opencode/src/acp/service.ts , https://github.com/anomalyco/opencode/blob/v1.18.32/packages/opencode/src/acp/agent.ts , https://github.com/anomalyco/opencode/blob/v1.18.32/packages/opencode/src/acp/config-option.ts , https://agentclientprotocol.com/protocol/v1/schema .

`rpc_journal::read_observed_acp_response` recovers an already observed metadata ACK from the exact original H step and A source. It does not re-read stdout or resend stdin. An INTENT, WRITTEN, or UNKNOWN setting remains unresolved and cannot be treated as applied.

The same fixed release's `packages/opencode/src/index.ts` defines global `--pure` as "run without external plugins" and sets `OPENCODE_PURE=1`; the launch uses it before `acp`. This reduces plugin loading but is not proof that memory is disabled or that a requested model was selected. Source: https://github.com/anomalyco/opencode/blob/v1.18.32/packages/opencode/src/index.ts .

Grok Build 1.0.41 fixed exe `agent --help` reports `Usage: grok agent [OPTIONS] [COMMAND]`, parent options `-m, --model <MODEL>`, `--reasoning-effort <EFFORT>`, and `--no-leader`; `stdio --help` has only debug/leader-socket options. Root's no-login/no-model help capture is `phase22/grok-agent-fixed-help-original/result.json` with exe SHA-256 `ab5d2a424f08281798acbdbb06076166fe000d7995ede94a673417b805210a25` and exit 0. The launch now requests both values from bound seat settings before `stdio`. The historical gogo-party seat used analogous argv but is not treated as proof of the fixed binary. Requesting flags is not proof of effective model or effort; Root must gate open on actual provider readback or report Unsupported, never silently accept a CLI default.
