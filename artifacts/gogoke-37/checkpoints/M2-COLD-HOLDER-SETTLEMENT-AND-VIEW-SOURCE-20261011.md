## 改动与结果

在已安装、同冻结字节的实验候选上，普通 Win11 的新 USER 连接自动结算旧失败持有者，并为秘书长建立新的 H。没有发送模型输入、重新登录、复制实例或手工改库。随后调用真实 H Stop，宿主及闭库读回确认新停止事实；原 shell/native 句柄退出均为零。

旧 UNKNOWN 和原 StopFact 保持原样；旧 ACTIVE 凭据记录按持有者消失结算，新 H 正常停止后无该实例 ACTIVE 残留。十三项正式保护前后相等。此结果仅证明本次真实冷启动结算、H 建立及停止，不代表完整秘书长、Claude 冷恢复问答或 M2/M3 通过。

一次并行快照从 Codex 的文件系统视图命中了 MSIX 缓存影子，虽文本路径相同，却不是普通视图基线里的对象。原误测保留，追加来源纠正。普通视图逐个文件句柄的实际路径和文件身份确认后，真实五个文件、四个目录及各文件字节均与基线相等，正式目录没有新增 WAL/SHM。撤回正式数据变化判断。

下一轻候选的同源受影响五项云检、Browser、卫生及冻结构建通过；公开密钥验签和八个产品文件与原 producer 字节核对通过。现已正常换装，安装器退出零，实际文件与已签冻结字节相等；十三项正式保护及完整候选记录连续性相等。安装和云检不计新增可运行能力。

OpenCode 五个授权 H 文件的独立静态复核发现共用钩子日志错误归属为 Claude，已按实际固定模式修正；Claude 原前缀保持，原 API 错误不变。聚焦独立复核无阻塞，六组受影响过滤项与两项同源 shim 测试在云端实际执行通过，原归档已核摘要并逐项回读，交付已集成。新模式选择、拒绝和日志归属进入同生产源码的边界测试；DLL 的实际启动接线及真实产品 OpenCode 初始化、会话和模型仍未运行，不从静态或开发结果推定通过。没有增加 ACL、能力、GIT_DIR、PATH 或改固定 CLI。

## 参照与决定

沿用现有 Interactive/Limited 普通视图快照、H Stop 与精确 pid/创建时间的持有者消失事实。文本路径、根句柄或进程未打包的读数都不足以证明子文件未被 MSIX 重定向，因此比较对象以普通视图每个原文件句柄为准，不新增恢复替身。新结算只记录独立的持有者消失结论，不补造 STOPPED；本次无需 Owner 登录，继续在已授权边界施工。
