# 施工控制台窗口

## 改了什么

Owner 反馈施工时小黑窗频繁出现在前台。核对实际进程和任务入口后，发现施工一次性计划任务的 PowerShell 参数未设置隐藏；现有产品后台启动代码已有 `CREATE_NO_WINDOW`，端到端 Node 子进程已有 `windowsHide`。

给后续任务入口加上 `-WindowStyle Hidden`，并同步原任务核对和清理入口中的参数。普通用户 `Interactive/Limited` 视图、原脚本、原日志、退出码及任务精确核对保持原语义。已完成任务的原 XML / custody 和启动脚本副本保留，不回写历史证据。

## 结果与下一步

更新后的现成模板已存入私有 D 盘施工工具目录，后续新阶段复制此模板后注册任务；控制台输出继续进入各自 D 盘日志。使用它继续下一条 V11 来源绑定和真机流程。此项是施工体验修正，不计产品真机能力，不声称已证明所有来源的窗口都不会出现。

随后准备原现场正常收尾时，一份新包复制了旧 Host 收尾模板，实际注册参数缺少 `Hidden`；先前静态复核对该参数的结论已撤回。该在途任务和原 custody 保留，按原参数完成清理；下一份闭库读取包已改用现行模板。后续启动前直接核对启动入口中的参数，启动后以注册任务的参数读回为准，不以副本来源或审计文字代替实际读数。

## 参照

采用现有 owned-task 启动/回读/清理脚本和产品后台隐藏启动方式，只补缺少的窗口参数；没有增加包装服务、改 CLI 或改系统安全设置。正常产品窗口与需要 Owner 操作的登录页面保持可见。
