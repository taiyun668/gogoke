原失败不是产品失败，也不计新增能力。秘书长通过原 capability / stop / 回读取得真实停止事实，保留会话；之后产品和宿主正常退出，退出码均为 0。普通视图闭库读回确认没有 ACTIVE / PREPARED 持有者，13 项正式保护比对一致。三个已应用的 USER 设置保留，不重放、不改账、不补造 STOPPED。

可选提升工具的独立聚焦复核无阻塞，指定源的卫生云检通过；真机结果仍在执行，不能写成通过。默认 V06 路径不增加提升操作。当前实例的真实 UI ERROR 和原生 LOGGED_IN / MANAGED READY 各自保留，不把显示状态改写为检测事实。
