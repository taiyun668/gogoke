# 新用户上手审计（以新用户身份攻击）

审计方：Grok（xAI）· 档案 ayun360-icloud-com · 只读
被审：docs/design/29-first-run-onboarding.md（补「一席一实例」那节之前的版本）
日期：2026-08-23

任务书要求它扮演一个具体的人：会用电脑但不写代码、**没有终端也不知道终端是什么**、
Windows、可能没装 Node、没听说过这三个 CLI 要单独装、卡住两次就关掉。
用第一人称写真实困惑，不做设计评审。

结果：20 条（13 高 / 6 中 / 1 低）。

---

## 我卡住的地方

### [严重度: 高] 一打开是空房间，我不知道这是什么软件，也不知道「席位」要我建什么
在哪一步：第一次打开产品。
我看到的：一个空的「房间」，和一个「新建席位」按钮。没有人用一句话说这是干什么的。
我以为的：软件打开后会告诉我它能帮我做什么、我现在该点哪。
实际发生的 / 我不知道该怎么办：「房间」「席位」对我来说都是开会的词。我不知道自己是来聊天、来找人帮忙，还是来填一份设置。我可能会点那个按钮，也可能觉得进错了软件，直接关掉。

### [严重度: 高] 「主控 / 施工 / 审计 / worker」我一个都看不懂，不知道自己该选哪个
在哪一步：点了「新建席位」之后选「角色」。
我看到的：四个选项，三个像工地/公司职位，还有一个英文 `worker`。
我以为的：「角色」是选它的性格，比如助手、翻译、客服。
实际发生的 / 我不知道该怎么办：我只是想要一个能干活的人。没有推荐、没有「第一次选这个」。我只能瞎点。点错了后面会怎样，界面没说。那个英文 `worker` 我以为是另一种完全不同的东西，更不敢选。

### [严重度: 高] 要我选 Claude、Codex 还是 Grok，我只有 ChatGPT，对不上
在哪一步：新建席位时选「厂商」。
我看到的：Claude / Codex / Grok。没有 ChatGPT，也没有「如果你有某某账号就选这个」。
我以为的：厂商就是我平时聊天用的那个 AI。我有 ChatGPT 就该能选 ChatGPT。
实际发生的 / 我不知道该怎么办：Codex 我没听过，不知道它跟 OpenAI 或 ChatGPT 有没有关系。Claude 我也许听过网页版，不知道这里要的是另一个要单独装的东西。Grok 也许听过。没有「新手选哪个」。我随便选一个，后面登录对不上号，我会以为是我账号不行。

### [严重度: 中] 还要选「模型」，全是一串我不认识的代号
在哪一步：新建席位时选「模型」。
我看到的：一长串英文型号；最后还有「手填其它模型…」。
我以为的：选好厂商就够了，模型要么自动，要么是套餐名字。
实际发生的 / 我不知道该怎么办：厂商和模型有什么差别我分不清。我会挑看起来最贵/最新的，或者挑第一个。没有「第一次用选这个」。

### [严重度: 高] 它突然说需要一个「实例」，我不知道那是什么，也不知道为什么要「准备」一个
在哪一步：选完角色和厂商之后。
我看到的：「需要一个实例」，没有可用的，要我「去准备一个实例」，然后被带到「实例管理页」。
我以为的：席位建好就该能说话了。最多再登个账号。
实际发生的 / 我不知道该怎么办：「实例」对我是空白词。我不知道它跟席位、账号、刚选的厂商是什么关系，为什么建一个人还要先准备一台我看不见的东西。这一跳不像继续创建，像被丢进另一张管理后台。我已经开始不想弄了。

### [严重度: 高] 安装卡上是 `npm install -g ...`，我没有终端，这条命令我贴到哪里
在哪一步：实例管理页，本机没装对应 CLI。
我看到的：一张安装卡、一句这是什么、一条能复制的命令、一个「我装好了，重新检测」。Grok 则是「去 x.ai/cli 安装」。
我以为的：点一下就会装，或者给我一个「下载」按钮，像装普通软件一样下一步、下一步。
实际发生的 / 我不知道该怎么办：我可以复制命令。贴到哪里？桌面？记事本？浏览器地址栏？对话框里？产品里没有黑色窗口，也没写「按 Win 键，输入 命令提示符」。文档自己也说使用者没有终端、出路必须是界面上点得到的，但这里唯一的路就是一条我无处可跑的命令。这是我会关掉软件的地方。

### [严重度: 高] 它说要先有 Node.js，但没把我带到能装完、能用的那一步
在哪一步：安装卡发现我没有 Node（我是 Windows，很可能没有）。
我看到的：先别跑命令，你需要 Node.js。
我以为的：它会给我官网安装包、告诉我点哪几个下一步、装完回这里继续。
实际发生的 / 我不知道该怎么办：Node.js 是什么、去哪个网站、装哪个 Windows 版本、要不要改勾选项，都没说。就算我自己搜到并装了，那条 `npm` 命令还是要有一个我不知道的窗口才能跑。装 Node 并没有让我更接近把席位用起来。

### [严重度: 高] 「产品不代替人安装」，对我来说就是第一关过不去
在哪一步：第 4 节这条边界落到我身上的时候。
我看到的：命令我自己复制去跑；产品只负责说明和检测。登录也是同样态度。
我以为的：我下载的这个产品，会把用它所需要的东西装好，或者至少给我一个安装程序。
实际发生的 / 我不知道该怎么办：我不会写代码、没有终端、也不知道 Claude Code / Codex / Grok 还要另外装。这条边界等于把第一次使用最关键的一步完全推到产品外面。我卡住一次（看不懂选什么）再卡住一次（命令贴不出地方），按我的脾气会关掉，不会再打开。

### [严重度: 高] Grok 让我去 x.ai/cli，我打开多半还是一页我跑不了的安装说明
在哪一步：选了 Grok、本机没装。
我看到的：「从 x.ai/cli 安装」，以及之后要 `grok --version`。
我以为的：点进去会下一个 Windows 安装包，双击就好。
实际发生的 / 我不知道该怎么办：这类地址通常还是给会用命令的人看的。我没有终端，验证命令同样无处可跑。三条安装路，没有一条是我能在界面里点完的。

### [严重度: 高] 我点「我装好了，重新检测」，它还是说没装，我只能再点一遍
在哪一步：我以为自己装完了（其实可能把命令贴到记事本里了，或者装了 Node 但没装 CLI，或装上了但 Windows 没刷新路径）。
我看到的：还是那张安装卡，唯一的按钮还是「重新检测」。
我以为的：它会告诉我缺哪一步，或者帮我打开该打开的地方。
实际发生的 / 我不知道该怎么办：出路表里「没装 CLI」的办法只有「装完点检测」。检测失败没有「仍找不到？重启产品试试」，没有「命令要贴到这里」，没有换一种安装方式。我会把同一颗按钮连点几次，然后放弃。就算我真的在别处装成功了，不关掉重开这个软件，它也可能一直看不见。

### [严重度: 中] 「发现本机 CLI」让我选「采用」还是「独立实例」，还警告终端和额度，我两个都不敢点
在哪一步：实例页最上面突然出现一条「检测到本机已安装 xxx，已登录」。
我看到的：可以直接用它建席位；跟我在终端里用的是同一份登录和额度；两个按钮「采用」「改为新建一个独立实例」。
我以为的：终于有个绿色的「可以用」的东西，点一下就结束。
实际发生的 / 我不知道该怎么办：我没有终端，这句话像在说会动我别的东西。额度是钱吗？会不会把我网页版的次数用光？「独立实例」更像要再装一套。没有「第一次请按采用」。我可能什么都不点，退回空房间。

### [严重度: 高] 登录弹出的是我不认识的账号，或者要我登 Anthropic / OpenAI，我的 ChatGPT 不知道能不能用
在哪一步：实例要登录。
我看到的：浏览器自己弹开，里面是我没见过的登录页，或电脑里缓存的某个 Google/微软账号。席位那边一个登录按钮都没有。
我以为的：用我已经有的 ChatGPT 账号就能登。登的是这个席位，跟刚才建的那个人绑定。
实际发生的 / 我不知道该怎么办：我选了 Claude，打开的是我不认识的公司；选了 Codex，也不叫 ChatGPT。能不能用我那个号，没人说。弹出来的如果是家里其他人的账号，我不敢换，也找不到「这不是我」。想换账号只能去实例页，席位上看不到登录入口，我会以为这个人没法登。登完我也不知道有没有登对。

### [严重度: 中] 浏览器根本没弹，我不一定找得到「进度区」里的授权链接
在哪一步：点了登录，什么都没发生。
我看到的：设计说进度区会给一条可点的链接。页面上同时可能还有「未完成登录」。
我以为的：没弹出就是坏了，或者我没联网。
实际发生的 / 我不知道该怎么办：「进度区」不是我认识的词。链接如果不醒目，我就坐在那等。等不到我会返回去乱点。我不会想到要自己打开浏览器贴一串地址。

### [严重度: 中] 登录到一半我关掉了，回来只看到「未完成登录」，旁边还能删掉
在哪一步：授权做到一半，窗口关了或电脑睡了。
我看到的：这个实例停在「未完成登录」，目录还在；出路是继续登，或删掉。
我以为的：再打开应该接着刚才那一步，把话说完。
实际发生的 / 我不知道该怎么办：继续登会不会又弹一个我不认识的号？删掉会删掉什么？「目录保留」我看不见，也不知道那是不是我的文件。两个选项我都怕。可能两个都不点。

### [严重度: 高] 没实例也能先把席位建出来，停在「等待实例」——我以为建好了，其实还不能用
在哪一步：安装太烦，我没装完就先把席位建了（产品还允许）。
我看到的：房间里多了一个人，状态写「等待实例」。
我以为的：人已经在了，点开就能说话。状态那几个字我可能根本没当回事。
实际发生的 / 我不知道该怎么办：我跟它说话不会回话。我以为软件坏了。设计是想让我先去别处、回头再补；我这种人不会回头补，我会觉得第一次就没用。空房间至少还逼我面对「还没建好」；现在房间里有一个假的人，更像已经完成。

### [严重度: 高] 席位显示「可启动」之后，我不知道怎么证明它真的能用
在哪一步：实例终于有了，草稿被送回来，席位建好。
我看到的：可以启动。没有「先对它说一句你好，看到回话就算成功」。
我以为的：建好就会像 ChatGPT 那样出现一个对话框，我打字它就回。
实际发生的 / 我不知道该怎么办：要不要再点启动？启动后等什么？没回话是还在加载，还是又缺一步？目标明明是「第一个席位真的回话」，界面却不带我走到那一句话。我不敢确定自己做成了，也不敢确定没做成。

### [严重度: 中] 我不会手填模型 id；真填错了，要等到启动才甩一句我看不懂的原话
在哪一步：选模型时看到「手填其它模型…」；或列表里的名字启动时 CLI 不认。
我看到的：允许我自己填一串 id；不行的时候把 CLI 的报错原样拿来（密钥会遮住），实例卡上有个版本号。
我以为的：能填的框我也许该填，像序列号一样。列表里的都是能用的。
实际发生的 / 我不知道该怎么办：我不会填模型 id。如果我把「gpt-4」「chatgpt」「claude」打进去，或者列表里那个型号对不上我刚装的版本，失败发生在我已经装完、登完、建完之后。那时屏幕上是一截英文报错加一个版本号，没有「回到列表里选一个」。这会变成最后一根稻草。

### [严重度: 高] 中途关窗口或重启后，只要我留过「实例」，就不把我当第一次——我找不到刚才那条路
在哪一步：装 CLI / 登录 / 建席位做到一半，关掉软件或电脑重启，再打开。
我看到的：判定「是不是第一次」只看：有没有 managed 实例，以及有没有席位绑了实例。不是看我有没有成功说过一句话，也不是看我是不是第一次打开。草稿只说了「跳去实例页时别丢」，没说整个软件关掉后还在不在。
我以为的：再打开会说「你上次做到登录/安装，点这里继续」。
实际发生的 / 我不知道该怎么办：
- 我若已经点出过一个实例（哪怕没登录成功），再进来就不是「第一次」，空房间那条「新建席位 → 领去准备实例 → 办完送回来」的主线不会再领我。
- 我若按「没实例也能建席位」先建了一个「等待实例」，房间里已经有人，但席位没绑实例——它可能仍把我当第一次，又推我去再建一个，两个半成品堆在一起。
- 这台电脑如果以前有人用过，留下实例或绑过席位，我第一次打开也不会被当成新的，我会直接看见一堆不是我的账号和灰掉的选项。
我不会自己摸去实例管理页把半截登录续上。第二次打开对不上记忆，我会以为上次白弄了，不再打开。

### [严重度: 中] 实例卡上写版本旧、可能有些功能用不了，但又不拦我，我也不知道怎么更新
在哪一步：后来某次检测，实例卡提示版本比验证过的旧。
我看到的：警告，仍能用；产品不会帮我升级。
我以为的：要么它替我更新，要么告诉我点哪个按钮更新。
实际发生的 / 我不知道该怎么办：更新又是命令、又是终端。我刚为了第一次安装已经不会了。我会无视警告；真坏了还是看不懂的报错。

### [严重度: 低] 「回到 @xxx 的创建」这几个字我不像是在叫我
在哪一步：在实例页终于弄出可用实例之后。
我看到的：实例卡多一条「回到 @xxx 的创建」。
我以为的：办完会自动回到刚才那一页，或有一个很清楚的「继续创建席位」。
实际发生的 / 我不知道该怎么办：`@xxx` 像网名或内部编号。我不一定敢点。如果我关过软件，这条入口还在不在更不知道。
