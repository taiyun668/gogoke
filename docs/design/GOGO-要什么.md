# GOGO 要什么

2026-09-16，Owner 口述、确认。这份只说**要什么**，不说现在有什么、也不说用哪套壳去实现。
细节看 `<local>\gogo-ui-research\2026-09-13` 的五份研究；这里每条后面标的是它在研究里的出处。

## 一句话

你说出一个要的结果，一支 AI 团队把它做出来，做完了你点头。

## 你在管的只有三样

正在推进的工作、跟主控的对话、能看和能用的成果。团队、过程、证据都在工作里面，要看才展开。
不需要先学会房间、席位、回合这些词。
（《工作主路径研究》§1、§3）

## 一次完整的使用

你说"商品卡太挤，改清楚，价格别动"。主控听懂，把活分下去。事情在跑，你看到一条能读的进展，想细看就展开。
中途谁有问题，先找主控；主控能答就自己答了，答不了才来问你一句。
你喊停它就停，不会自己往前冲。（**2026-09-16 Owner 修订**：对账、花费上限这些闸门首版不做。）
做完了给你成果本身：能点的页面、能读的文档，不是一串文件名。你指着说"这里不对"，它知道你指的是哪一版的哪个位置。
你看过就完了——你接着说就是继续，不说就是到此为止，跟 Claude Code、Codex 一样。（**2026-09-16 Owner 修订**：原写"点一下验收"，取消。只有当真有一个会改你仓库、又只能你授权的动作没做时，那一下才出现，并写清是什么动作。席位怎么干活由主控定夺，产品不定死。）
（《工作主路径研究》§10 的连贯目标体验）

## 界面上必须有的七样

1. **一件工作** — 稳定的入口，昨天那件今天还能找回来。（主路径 §3；验收场景 U18）
2. **一条主对话** — 你只跟主控说话。（五家产品研究 §8「默认只和主控聊」）
3. **正在进行** — 谁在做什么，永远在主控输出的最下方，主控说的话堆在它上面。（主路径 §9 信息密度）
4. **要你定的一下** — **只有真实的 CLI 问题**配占你的注意力（2026-09-16 修订：闸门首版不做）。（五家研究 §7 三类界面；组件拆解 C05/C06）
5. **成果** — 本体，带版本，能指着提意见。（主路径 §5；组件拆解 C08/C09）
6. **一眼看全** — 手上有几件事，哪件待处理，哪件你还没看过。（主路径 §3 的视图）
7. **侧边聊条与递话** — 你主动抓一个人问几句（**本项目审计、秘书长**；施工抓不到，施工的事一律走主控——2026-09-16 Owner 修正），和主窗共享当前目标的上下文；
   听完只把选中的那一句递给主控，带出处。递有两种时机：排队，或插进主控正在跑的这一轮。
   停机或对账期间只能跟只读的审计、秘书说话，它们不能改工作区、不能接力、不能动目标。
   旁聊里的话不算数，除非你递过去。（《项目上下文共享与隔离》§3；主路径 §7）

## 你对接的是谁（2026-09-16 Owner 补充）

两个面：**全局的秘书长**，服务你本人、跨项目；**项目的主控和审计**，一个项目固定各一个（绑在项目上，不绑在对话上）。
左栏是秘书长加项目工作区，工作区下面是它的对话；**点开的是一条对话，一条对话就是一件工作**——跟 Codex、Claude Code 一样。
主控在你给的授权范围内自己拉席位、拉角色，不必回来问你。目标只能属于本项目；一个主控管本项目下的多条对话。
**角色管理是侧边窗口里的一页**，入口在中顶靠右；**实例管理在设置里**，那是全局的。
你会同时开着几个项目——切走不等于停下。角色不绑 CLI：角色 → 席位 → 实例 → 进程，四层解耦，同一个实例服务不同项目的席位时项目级隔离照做。

**首版只做代码生产**，其余先不管。

**长期愿景**：说一句"做一个生产级系统"就一路跑到交付。首版不按这个尺度设计，但任何一处都不得假设你一直看着。

## 系统必须守住的六条

- 席位不直接跟你说话。有问题先交给主控。
- "跑完了"不是"做好了"，"做好了"不等于改动已经落到你手上。这几种完成严格分开——**这是措辞规矩，不是几个按钮**。（五家研究 §7）
- 交给下一个人的是仓库里的东西，不是上一个人的转述。
- 审计必须是干净的会话，否则就不许叫审计。（上下文研究 §3、§4 记着的缺口）
- 不知道就说不知道：送达没回执、用量没返回、停了没确认，都如实写。
- 产品不替模型出题，也不替你做决定。
