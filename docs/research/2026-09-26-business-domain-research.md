## 0. 这批调研里最出乎意料的发现

1. **亚马逊给 agent 定了四条硬规则，原文很短。** [核] 读的是亚马逊卖家中心 Agent Policy 原文，2026-03-04 起随商业解决方案协议生效。适用对象是一切代表人自主或半自主行动的软件。
   - 每个 HTTP 请求的 User-Agent 里必须带 `Agent/[agent 名]`；
   - 不得隐藏自己是 agent：不得模仿人的按键速度或浏览节奏，不得完成或绕过 CAPTCHA；
   - 被问"是人还是机器"时必须如实回答；
   - 不得绕过亚马逊用来限制 agent 的任何措施。

   另外，按亚马逊论坛公告，亚马逊要求停止访问时必须停止。协议同时新增了"不得用亚马逊材料开发或改进 AI"。
2. **中国 AI 客服有了第一部国家标准，三份报告都没提到。** [核] GB/T 47746-2026《顾客联络服务 人工与智能客户服务协同要求》，由国家市场监督管理总局和国家标准化管理委员会发布，**2026-09-01 实施**，推荐性标准。
   - 转人工入口要清晰醒目，不得层层隐藏；
   - 简单高频的交给 AI，复杂问题、安全问题和用户主动要求的转人工；
   - 转接时要把身份、对话历史和工单状态一起带过去，不让用户重复说明；
   - 支持关键词、菜单、语音等多种转接方式；多轮答复仍未解决、或涉及安全时自动转人工。

   媒体报道：它会成为处理投诉和纠纷时的参照；有省级通信管理局已开始抽查。
3. **那家"一人加 35 个 agent"的营销公司，调度层用的是 Multica。** [核] multica-ai/multica 在 GitHub 上有 51,352★，Go 语言，2026-01 创建。
   - 定位：像给同事派活一样给 AI 编码 agent 派议题。agent 自己领取议题、汇报进度、提出阻塞、交回审阅；支持 26 种 agent CLI，可自托管。
   - 许可证：Apache-2.0 加附加条件。不得未经商业授权作为托管服务提供给第三方，或嵌入对外销售的产品；不得去除其界面上的名称和标识；单一组织内部使用不受限。
   - 在 gogoke 的 S1-R3 决定里，它被列为"机制参考"。
4. **Sora 的视频 API 已于 2026-09-24 关停，没有继任模型。** [核] OpenAI 在 2026-03-24 宣布停止 Sora：App 在 04-26 关闭，API 在 09-24 关闭，包括 sora-2 和 sora-2-pro 的全部版本。
5. **"AI 假图"是双向的。** [核] 淘宝天猫在 2026-01-20 宣布：
   - 上线售后 AI 假图识别模型，针对买家用 AI 伪造破洞、污渍来骗取退款；
   - 训练阶段准确率超过 95%，**召回率约 50%**；
   - 识别结果逐步接入纠纷判决和退款环节。

   与此同时，卖家用 AI 美化商品图，会按"货不对板"被拦截或处罚（见 §2.3）。
6. **支付平台明确：agent 犯错，由客户担责。** [待] 按 GPT 报告引用的 Stripe Console 条款（2026-04-29 修订）：
   - 用户必须在执行前独立核验每个拟执行的动作；
   - 未经审阅、超出授权、或由 bug 和幻觉造成的动作，都视同客户本人所为。
7. **公开的"一人加 AI"业务都有人在环。** 已核的几例：
   - Polsia 的自报材料写"80% 自治"[核]；
   - 那家营销公司的 agent"没有明确授权不能行动"[待，Forbes 付费墙]；
   - Anthropic 的 Project Vend 实验里，搬货和检查由人完成，agent 被顾客说服反复打折，还"幻觉"出一个收款账户 [核]。

### 1.4 身份披露与标识

- [核] 中国《人工智能生成合成内容标识办法》，国信办通字〔2025〕2 号，2025-09-01 施行（gov.cn 原文）。
  - 显式标识：文本在开头、结尾或中间；音频用语音提示；图片在适当位置；视频在起始画面和播放周边。
  - 隐式标识写入文件元数据：生成属性、服务提供者名称或编码、内容编号。
  - 用户申请不加显式标识的，要在协议里明确责任，并**留存日志至少 6 个月**。
  - 传播平台要核验元数据；不得恶意删除、篡改标识。
  - 违法的依据现有法律处理，办法本身没有单列罚金。
- [核] 配套强制国标 GB 45438-2025，同日实施。"图片文字高度不低于最短边 5%"出自第三方解读 [待]。
- [核] 欧盟 AI 法案第 50 条（聊天机器人告知、合成内容机器可读标记）**2026-08-02 起适用**。

### 2.5 Grok 列出的"没问到但会卡住全自动产线"的因素（照录，未核）

- 图和货必须一致。只换背景也可能被模型顺手改色、拉长或重绘 LOGO。
- 一次通过率不到 100%，需要质检和定向重修。有效成本等于单价乘以重试次数，也就是"每条可上架素材的成本"。
- 开源权重不等于可以商用部署（见 §2.1）。
- 转码、截图会剥掉元数据，像素水印还在。故意剥离标识本身违法；自动导出时必须重写隐式字段并加显式角标。
- 《广告法》的违禁词与 AI 标识是两套处罚。
- 生成图案趋同，更容易被跨境图搜批量起诉（Schedule A）。
- 肖像和声音需要授权台账。
- SKU 事实要用结构化参数表锁定，不能只靠提示词。
- 单一闭源视频 API 可能突然停服（Sora 已经发生）。
- 批量同构图会被内容平台按同质化限流。
- 各平台分辨率、比例、安全区不同，导出本身是工程问题。
- 合规台账字段：模型与版本、文件哈希或内容编号、标识状态、提示词摘要、操作人、肖像授权号。
- 算力、队列与区域限制："每分钟稳定 1,000 张、零人工"的可复现案例，未找到。
