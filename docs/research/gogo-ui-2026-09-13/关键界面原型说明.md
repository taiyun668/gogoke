## 本次重点路径

1. **批注位置：** 打开报告v2，第一段写并保存意见，再点第三段。原意见保留在已保存列表，点回原意见再加入草稿，引用必须仍为第一段。再写第三段另一条意见，合并后两条各自保留位置与版本。固定B、主对话A时，主动作明确打开B并保留A草稿。
2. **审查到完成：** 从本轮交付准备三项精确版本的审查请求，发送；通过标明“模拟”的回执展示不通过批次；将整批意见交主控修订，收到新集合后重新审查；逐项查看待确认版本，再由Owner点一次“确认这3项完成”。确认前新版到达时旧集合不能确认；新一轮开始后旧确认只保留历史。
3. **通用五栏：** 对照“制作结束待主控安排审查”“审查失败需要处理”“旧轮已确认、新轮制作”这些样例，分别观察归栏、运行标记和依据，不以颜色猜状态。
4. **首次使用：** 进入首次使用场景，从空普通文件夹示例开始。绑定前写草稿，选择需登录/占用/未知连接时不能发送，换到明确可用连接并显式绑定后，发第一条请求；此前没有报告、审查或已完成成果。可选团队不是必填问卷。
5. **格式范围：** 首批格式与选择的转换/查看路线在主稿§9.4。原型SVG封面是绘图示意，媒体/Office不是实际解码和转换验收，不能据此推断产品支持格式。

## 1. 七个场景

| 场景 | 可以操作什么 | 用来判断什么 |
|---|---|---|
| 报告项目 | 写草稿、换收件人、打开CLI问题示例并提交、打开报告 | 主控对话是否清楚，提问是否安静、稳定，不挤掉底部输入 |
| 软件 + 通用 | 切同项目的两个最近对话，打开工作详情和不同成果目录 | 两类工作如何共存，模式不常驻，也不更改正在进行的工作 |
| 看板 / 画布 | 切分栏/图谱，点选、拖节点、拖背景，空白/Escape清选，缩放/适应 | 同一对象的不同视图、状态边缘与重要性面积；本原型展示近景卡片，完整圆形远景复用现有产品组件 |
| 成果查看 | 报告段落、CSV单元格和Shift范围、SVG对象、幻灯片页、模拟媒体区间 | 反馈能否准确落在某成果、版本和位置，而不要求用户报代码文件名 |
| 资料与审查 | 查看示例正文/来源、加入输入、模拟工具读取、查看记录 | 查阅、加入与有读取证据不同；报告v1审查不证明其他成果或v2通过 |
| 设置 | 六组设置、搜索、修改示例值、演示保存失败/成功 | 范围、生效时机、连接状态与保存反馈是否能看懂；没有真实配置变更 |
| 断线演示 | 未知送达、核对、排队撤回、模拟停止回执 | 未知不重发，撤回不是失败，停止不等于回退文件 |

顶部“原型场景”是评审用的示例导航，不是拟加入产品的项目阶段条。窗口与面板状态会保留；如果此前收起了右栏，可以点右侧“展开工作区”恢复。日常产品界面只有对话/看板和按需成果、资料、旁聊。

## 2. 两条需要重点体验的路径

**反馈不串工作：** 在“软件 + 通用”里给软件工作A留草稿，切通用工作B打开报告并固定右栏，再回A。只看B或写批注不会改变A；“加入此工作草稿”会明确打开B并保留A。另一个“引用到当前对话”是把素材拿给A讨论，不是默认修B。

**反馈不串版本：** 报告v2写批注，切到v1写另一条，再回v2；各自内容和定位保留。加入草稿时能看到成果、版本和位置。表格可以点击一个格子，再按住Shift点击另一个格子得到A1范围。

发送留下本工作、本收件人的示例记录；跨工作草稿保留。报告v2与v1批注独立，固定B反馈归B且A草稿保留。CSV范围B2:C3、第三页演示稿、SVG标题对象、媒体5–80秒区间都有对应定位。模拟保存失败保留选值；未知送达禁重复发送，撤回显示已撤回；停止先请求中，再模拟确认，文件版本保持不变。

这些是原型的代表性交互检查，不是产品正式三门或真实Provider验证。过程中改动过的固定视图、图谱、资料和原题路径已在修复后复查；不能将截图或局部点击外推为整个产品已验收。
