## Interface and custody

Import `runRulesCase(product, config, journal)` using the existing M2 `ActualProduct` instance and original `gogoke.37.m2-win11-e2e.v1` journal. Importing the module performs no operation. The shared runner owns candidate byte verification, launch, normal close, original journal saving and the final reader invocation.

`config.rules` requires `lifecycleOwnership: 'EXCLUSIVE_V08_SUBMITTER_AND_REVIEWER'`, `policyOwnership: 'EXCLUSIVE_V08_POLICY_DOMAIN'`, `submitterSession`, `reviewerSession`, and `baselineReadback: {file, sha256}`. Each session is the actual object already in `journal.sessions`, with `{id, seatId, instanceId, worktreeId, generation, revision, cursor, events, turns, threadId}` from real H admission/open/resume. Seats and host-registered worktrees must be distinct; both actual CLI processes must be Codex. Use only already authorized `gogokeSeatTestbed` worktrees/seats. The runner must finish any other work using the policy domain before this case: the final legal transition changes its current stage. The module creates no seat/session/worktree and stops/releases no other process.

Before opening/resuming these two sessions, normally close the candidate and run signed Python `tools/e2e/m2-rules-readback.py STATE_ROOT FRESH_PRIVATE_OUTPUT M2_JOURNAL before`. The existing native Owner-initialized policy head is required. Put this artifact in `config.evidenceDirectory`; inject its basename and original byte SHA256, then normally launch/open or resume the two exclusively owned sessions. A private configured policy revision or stage cannot replace the native artifact. The reader's Python root identity is an observer fact; it is not a native opaque identity.

The module records `journal.rulesCases[]` (one case), original Owner configuration frames/receipts in `journal.operations[]`, original K-SEAT card request IDs, every model ask byte string, send request/receipt, exact CLI turn ID and native tool receipt. `ActualProduct.operation` persists the original User frame before sending once. Owner configuration uses the same real User invoke and persists its original string before sending once. Readonly STALE reads get a new ID/current revision; mutations are never retried. Unknown errors, unexpected cards, additional tools, missing original completion or native reply terminate the flow and preserve original error text. No question card is auto-answered.

On `FLOW_COMPLETE_DIRECT_LEDGER_READBACK_REQUIRED`, normally close the candidate and run the same reader with `final`. Its fresh private output must be in the baseline artifact directory. The reader opens only `state.sqlite` using `mode=ro&immutable=1` and `query_only`, refuses a nonempty WAL, compares database/WAL/SHM bytes before/after and exports only scoped policy rows and the case's original A/H frames. It ties original User asks to H stdin and the actual turn/start command/CLI ACK, original A `item/tool/call` to a written H response using typed RPC IDs and physical custody, and applied native receipts to committed policy events. Stored K-SEAT cards, actual Codex binary pin and physical StopFact are checked. It verifies exact final gate/head/grant states and unchanged unrelated policy events/rows. Denied model calls must have an original H DENIED reply and no policy event; denial evidence lives in the original A/H protocol, not an invented denial table. The User UNSUPPORTED control has only its original User receipt; it is explicitly not a persisted model denial row.
