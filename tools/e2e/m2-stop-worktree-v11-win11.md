# V11 installed file-boundary entry

`m2-stop-worktree-v11-win11.mjs` gives the existing `m2-v11-boundaries.mjs` and `m2-v11-readback.py file` one explicit installed-product entry. It invokes the original User E/F reads and H reserve, commit, open, send, output, stop and release for the main-source and READ_ONLY F-tree attempts. It then normally closes the same candidate and reads the original A/H/F rows and exact tool result from the immutable database. A failed tool remains cause-unattributed until the original result supports an OS/LPAC conclusion; model prose or generic DENIED never establishes one.

Run with signed Node and a fresh private config, after two separate runs of `m2-stop-worktree-prepare.mjs` have produced distinct registered SINGLE worktrees and IDLE USER seats in the same `gogokeSeatTestbed` domain. Use an existing eligible `NETWORKED_WRITE` template for the main-source attempt and an existing eligible `READ_ONLY` template for the second. The V11 entry rechecks each exact seat state, tier and F graph before opening H. Do not rerun a preparer after it has mutated its original fixture.

```text
node tools/e2e/m2-stop-worktree-v11-win11.mjs PRIVATE_CONFIG.json
```

The config carries the same installed byte pins, source commit, `stateRoot`, `testbedSource`, signed `pwsh`/`python`, `domainId`, `repositoryId: "gogokeSeatTestbed"`, new `evidenceDirectory` and nonexistent `result` path required by `m2-stop-worktree-win11.mjs`, plus:

```js
v11FileBoundaries: {
  ownership: 'EXCLUSIVE_V11_FILE_BOUNDARIES',
  mainWrite: { seatId, instanceId, worktreeId, worktreePath, attemptMode: 'execCommand' },
  readOnlyWrite: { seatId, instanceId, worktreeId, worktreePath, attemptMode: 'execCommand' },
}
```

`seatId`, `instanceId`, `worktreeId` and `worktreePath` must come from each original final preparation proof and its state-card/F graph, not a display label or guessed path. Supply the workdir in its ordinary DOS spelling for the original CLI tool; the reader verifies that it is the exact registered F object even when the host record uses extended-length spelling. The script generates a fresh nonsecret marker and uses one exact native `exec_command` per case; unexpected tools, failed H custody, an unchanged or mismatched original receipt, target creation or readback failure stop the run without replay. Preserve the original journal and process on failure.

The same run then reuses the stopped and released `mainWrite` seat/F tree for one separate original H turn against a new **empty private D directory** outside the candidate, source, evidence, repository and all registered F worktrees. Add:

```js
v11OutsideTree: {
  ownership: 'EXCLUSIVE_V11_OUTSIDE_TREE',
  outsideRoot: '<fresh empty private D directory>',
}
```

Before candidate launch or any model input, the runner verifies no active candidate process and calls `m2-stop-worktree-v11-readback.py preflight` on the closed, empty-WAL database. That immutable read seals the complete existing F worktree and repository-source rows with their physical identities and refuses an `outsideRoot` overlapping any of them. Its private file hash is bound into the journal before launch. This package creates no F/source registration; the final closed read repeats the same inventory and requires exact equality.

The outside attempt asks for one exact native `exec_command` to create a new marker. The final reader checks original E tier and F registration, H input/turn/StopFact/release, A thread/start, turn/start, typed ACK and matched original tool pair, absence of any outside file, and unchanged database/WAL/SHM bytes. A failed original command is evidence of that attempt; its error and exit code remain visible for Controller to attribute. `directCaseEvidence` and `permissionCause` remain false/unattributed until that review.

The existing `m2-mainflow.mjs` host-sealed merge and two-project MIXED graph exports remain their own entries. This script does not exercise NO_NETWORK, and its original failed command results alone cannot attribute a permission cause. The output always has `acceptance: false`; a nonzero readback or a missing original tool is `NOT_RUN` or failure, never PASS.

Reference: `artifacts/gogoke-37/checkpoints/M2-HOST-COMMIT-AND-PROVIDER-FLOW.json` records the gogo-party `commitForSeat` host-seal precedent and its difference from design 37. This entry reuses the existing H/A/F V11 boundary driver and closed reader; it adds no model Git action or host merge substitute.
