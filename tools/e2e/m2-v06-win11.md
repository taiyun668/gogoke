# M2 V06 installed-product adapter

`runV06InstalledCases(product, config, journal, hostRoot)` is imported by the
single installed-candidate controller. It requires the **same** `product` and
`journal` objects held by `hostRoot`, plus a live original H `sessionId`, two
real project/template fixtures, and a separate registered idle LEAD seat.
It never opens a CLI, starts a model, closes the app, or reads SQLite itself.

`hostRoot.originalModelAttempt(details)` sends the supplied one-tool prompt
through that already open H session and returns its actual `domainId`,
`sessionId`, `sendRequestId`, and completed `turnId`. The wrapper passes the
callback to `m2-seat-management.mjs`; the normally closed immutable reader
then follows the raw H send, A tool call, H-written native DENIED receipt and
stop fact. An arbitrary JavaScript return object alone is not proof.

`hostRoot.normalCloseReadbackRestart(phase)` first settles and stops all live
H sessions, normally closes the installed product, runs the existing
`m2-seat-management-readback.py` against that closed product root, and restarts
the same installed bytes. It returns `{ file, sha256 }` for baseline and final.
The existing reader requires the original candidate and physical root identities,
saved request/receipt bytes, untouched template rows, and exact copied settings.
The original H session must be restored after baseline before the model callback.

The wrapper refuses to run when either original callback or the LEAD fixture is
missing. Its returned coverage names only template copy/tune, original model
denial, and User LEAD tune/reclaim; `acceptance` remains false. The remaining
V06 axes are returned explicitly. The Controller adds distinct real K-SEAT
receipts and immutable readback for set-bounds, lead refusals, busy change and
stop/reclaim, short-to-long, admission load cap, and host choices before V06
can be assessed. The frozen K-SEAT contract does not permit a User request to
stand in for a model-origin denial.

Signed Node syntax check:

```powershell
node --check tools/e2e/m2-v06-win11.mjs
```

This entry is not a standalone executable because the HostRoot callbacks and
live session can only come from the controller of the installed product. The
standalone `m2-seat-management-win11.mjs` remains useful for its narrower User
copy/tune case and honestly marks missing original H cases NOT_RUN.

## Native USER bounds and direct/child capacity

`runV06NativeUserCases(product, config, journal, hostRoot)` in
`m2-v06-native-user.mjs` is a separate installed-product entry. Import has no
side effects. It needs the same live `ActualProduct` and journal, and a private
`v06NativeUser` fixture: `lifecycleOwnership` is
`EXCLUSIVE_M2_V06_NATIVE_USER`; `domainId`, `parentSeatId` and `instanceId`
equal the existing test project, USER parent (`config.seatId`) and verified
instance; `templateId`, `directSeatId`, `childSeatId`, `deniedChildSeatId`,
`model`, `effort` and `permissionTier` are exact, disjoint test identities and
the existing parent/template settings. The parent must be IDLE with no current
LEAD children. The already configured Owner project cap is read, never set by
this case. This entry returns `NOT_RUN` before any write if the original H or
normal-close callback is unavailable.

Run this entry before opening the parent H session. It sends an original USER
`K-SEAT/set-orchestration-bounds` missing `maxConcurrent` and requires DENIED
without a revision/settings change; then it sets exact one-child bounds with
`maxConcurrent: 1` and creates an independent USER direct seat from the
existing template. `hostRoot.originalModelAttempt` must open the original H
session on its first call and send the supplied one-tool prompt. Its second
call must use that same session. It returns actual
`{domainId,parentSeatId,sessionId,sendRequestId,turnId}` and saves the H send's
original `rawFrame` and `rawReceipt` in the same journal. The prompts ask for
one native `gogoke_seat create-from-template` LEAD child and a second child
that must be denied at the source-backed one-child limit. The callback cannot
replace the model call with a USER operation. Missing tool call or receipt is
failure, not an inferred child.

`hostRoot.normalCloseV06ReadbackRestart(phase)` settles/stops the original H
session, normally closes the same candidate, invokes signed Python
`m2-v06-readback.py STATE_ROOT OUTPUT JOURNAL baseline|final`, then restarts
the same installed bytes and returns `{file,sha256}`. Baseline runs before
USER writes; final runs after both original model turns. The reader opens the
closed `state.sqlite` with `mode=ro&immutable=1`, requires empty/absent WAL,
checks unchanged measurement bytes, existing template and project cap, exact
USER receipts, original H/A tool calls and H-written native receipts, StopFact,
one durable non-reclaimed direct LEAD child, and no row for the denied second
child. The direct USER seat remains separate from that child. Returned state is
`READBACK_COMPLETE_REVIEW_REQUIRED`, with `acceptance:false`; the other V06
axes remain listed for Root review.

Syntax only, without launching the candidate or a model:

```powershell
node --check tools/e2e/m2-v06-native-user.mjs
python -c "import ast,pathlib; ast.parse(pathlib.Path('tools/e2e/m2-v06-readback.py').read_text(encoding='utf-8'))"
```
