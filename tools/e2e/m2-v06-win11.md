# M2 V06 installed-product adapter

`runV06InstalledCases(product, config, journal, hostRoot)` is imported by the
single installed-candidate controller. It requires the **same** `product` and
`journal` objects held by `hostRoot`, plus a live original H `sessionId`, two
real project/template fixtures, and a separate registered idle LEAD seat.
It never opens a CLI, starts a model, closes the app, or reads SQLite itself.

`hostRoot.originalModelAttempt(details)` sends the supplied one-tool prompt
through that already open H session and returns its actual `domainId`,
`sessionId`, `sendRequestId`, and completed `turnId`. The wrapper passes the
callback to `m2-seat-management.mjs`; the normally closed immutable reader
then follows the raw H send, A tool call, H-written native DENIED receipt and
stop fact. An arbitrary JavaScript return object alone is not proof.

`hostRoot.normalCloseReadbackRestart(phase)` first settles and stops all live
H sessions, normally closes the installed product, runs the existing
`m2-seat-management-readback.py` against that closed product root, and restarts
the same installed bytes. It returns `{ file, sha256 }` for baseline and final.
The existing reader requires the original candidate and physical root identities,
saved request/receipt bytes, untouched template rows, and exact copied settings.
The original H session must be restored after baseline before the model callback.

The wrapper refuses to run when either original callback or the LEAD fixture is
missing. Its returned coverage names only template copy/tune, original model
denial, and User LEAD tune/reclaim; `acceptance` remains false. The remaining
V06 axes are returned explicitly. The Controller adds distinct real K-SEAT
receipts and immutable readback for set-bounds, lead refusals, busy change and
stop/reclaim, short-to-long, admission load cap, and host choices before V06
can be assessed. The frozen K-SEAT contract does not permit a User request to
stand in for a model-origin denial.

Signed Node syntax check:

```powershell
node --check tools/e2e/m2-v06-win11.mjs
```

This entry is not a standalone executable because the HostRoot callbacks and
live session can only come from the controller of the installed product. The
standalone `m2-seat-management-win11.mjs` remains useful for its narrower User
copy/tune case and honestly marks missing original H cases NOT_RUN.
